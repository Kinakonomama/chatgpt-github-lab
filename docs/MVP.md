# FIP治療記録アプリ MVP

## 目的
FIP治療中の猫について、飼い主・家族が投薬、体重、体温、体調、検査結果を記録し、後から経過を確認できるアプリを作る。

## MVPで記録するもの
- 猫プロフィール
- 治療開始日とDay表示（84日を記録テンプレートとして扱う）
- 体重、体温、食欲、元気、メモ
- 薬名、剤形、投与量、単位、予定時刻
- 実施者と実施時刻
- 同じ薬・同じ予定枠の二重記録チェック
- 血液検査の記録枠
- 検査結果写真の選択・表示（現段階では端末内プレビュー）

## 安全方針
このアプリは獣医師から指示された治療内容を記録・共有するためのものとする。体重などから薬の投与量を自動決定したり、治療方針を診断・指示したりしない。
