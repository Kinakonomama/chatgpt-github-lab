# クラウド共有の設計方針

## 目的
複数のiPhone/Android/PCから、同じ家族の猫の治療記録を安全に共有する。

## 役割
- 認証: 利用者本人を確認する
- Family: 家族単位の共有範囲
- Member: Familyに所属する利用者
- Cat: Familyに所属する猫
- MedicationRecord: 誰がいつ投薬したかを保存
- Exam/Photo: 検診結果と写真を猫に紐付ける

## 権限
利用者は自分が所属するFamilyのデータだけを読み書きできるようにする。
Family IDを知っているだけではアクセスできない設計にする。

## 秘密情報
APIキー、サービスアカウント秘密鍵、パスワード、SSH秘密鍵などはGit管理しない。
本番用秘密情報はホスティングサービスのSecret/Environment Variableで管理する。

## 開発順序
1. 認証方式を決定
2. 開発用クラウドプロジェクトを作成
3. Family/Member/Catのアクセス制御を設定
4. 投薬記録を同期
5. 検診・写真を同期
6. 自動テスト
7. 本番環境を別プロジェクトとして作成

## 注意
このアプリは治療内容を決定するものではなく、獣医師の指示を記録・共有するためのものとする。
