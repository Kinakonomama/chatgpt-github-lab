# 開発用クラウド環境

## 採用候補
Supabaseを第一候補とする。

理由:
- 認証、PostgreSQLデータベース、ファイル保存をまとめて扱える
- Web/PWAから利用しやすい
- Row Level Securityで「自分の家族のデータだけ」を制御できる
- iPhone、Android、PCのブラウザから同じデータを利用できる

## 開発環境と本番環境
最初は開発用プロジェクトだけを使用する。本番用プロジェクトは公開直前に別途作成する。

## 次の作業
1. 開発用Supabaseプロジェクトをユーザー自身のアカウントで作成
2. URLと公開用Anon Keyをアプリの環境変数として設定
3. データベースのテーブルを作成
4. Row Level Securityを設定
5. 認証を追加
6. 家族招待を追加
7. 投薬記録のリアルタイム同期を追加

## 秘密情報
Service Role Keyなどの管理者用秘密鍵はGitHubへ保存しない。公開用キーについても環境変数を使い、秘密値をコミットしない。
